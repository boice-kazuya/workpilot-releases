WorkPilotは、チャットでAIに指示して**動画・画像・記事・コード・音声**を「作り終える」ところまで運ぶMac用デスクトップアプリです。案を出して終わりのチャットではなく、仕事を最後まで進める**操縦席**。

## 6つのモードが、ひとつの窓に

| | モード | 出てくるもの |
|---|---|---|
| 💬 | **相談** | 調査・整理・意思決定（自分の資料を読ませた状態で） |
| 🖼 | **画像** | 商品写真・参考画像をもとにしたビジュアル |
| 🎬 | **動画** | 生成 → タイムライン編集 → 書き出し |
| 📝 | **記事** | SEO構成 → 執筆 → WordPress投稿まで |
| 🎵 | **音声** | ナレーション・音楽 |
| 💻 | **コード** | 計画・実装・修正・デプロイ（Claude Code同等） |

## WorkPilotの特長

### 🧠 全エンジンをひとつの操縦席で — 手持ちのサブスクがそのまま動く

**Claude・ChatGPT・Kimi・Gemini** をスレッドごとに切り替え。「台本はClaudeで、サムネはGPTで、アップはClaudeで」と1つ指示すれば、工程を分解してエンジンを自動で使い分けます。各社の公式CLIログインで動くため **APIキー不要・従量課金なし**。プランの残量（5時間枠・週次枠）は画面下に常時表示。長いWeb調査は自動的に安いモデルへ切り替わるので、**調べもので枠を溶かしません**。

### 👥 1人のアシスタントではなく「AIのチーム」

**17職種のプリセット**（企画・調査・ライター・レビュアー・マーケ・デザイナー・コーダー・動画ディレクター・分析・法務…）＋自作エージェントでチームを編成。指揮官が采配し、「1:テーマ決定 2:台本(GPT) 3:チェック…」と**工程表**を書けばそのとおりに実行します。組み込みの役も**自社の呼び方に改名**でき、人物写真を設定でき、**指導した内容を覚えて育ちます**。エージェントは**ファイルに書き出して他の人へ渡せます**（書き出す前に、APIキーや個人のパスが混ざっていないか自動で点検します）。

### 🫧 分身エージェント「mee」

あなたの言い回しと判断の癖を観測してプロフィール化し、**ふだんの会話すべてに重なって効きます**——あなたらしい下書きを書き、あなたの基準で判断する。留守中の代返や、目的に向かった自走もできます。プロフィールへの反映は**必ずあなたの承認を通してから**。勝手に書き換えません。

### 🎒 一度「装備」すれば、説明し直さない

スレッドに**ナレッジ**（資料・仕様・商品写真）、**スキル**（「この流れをスキル化して」の一言で保存）、**外部接続**、**人格**を装着。組み合わせは**装備セット**としてワンタップで再現。

- **ナレッジ**はPDF・Word・Excel・PowerPoint・URL・写真（**OCR対応**）を取り込み、**OKF**（オープン標準）へ自動最適化。ただのファイルなのでロックインなし。
- **スキル**は既存の **Claude Code / Codex** からワンクリックで取り込み。最終使用日が記録され、削除せず「一時的に外す」こともでき、**効き目のA/Bテスト**まで内蔵しています。
- **外部接続**はひとつの画面に集約（MCP・自社API・SSHサーバー・メール）。
- 🛡 一度書いた**お約束（自社ルール）**が毎回の回答に効き、判断ログで後から検証できます。

### 🔁 ループ — あなたが居なくても回る仕事

一度きちんと相談したら、**「このスレッドからループを作る」**を押すだけ。決まったことが引き継がれ、足りない点だけを聞いてきて、定期実行に載ります。

- 設定した時刻に裏で自動実行。Macが寝ていて飛んだ回は、**後から遅れて実行**します。
- 途中でアプリを閉じても**続きから再開**。やり直しになりません。
- 毎回「やったこと」の報告と成果物が残り、結果を**メールで受け取れます**。
- 実行から**学習**し、人が見落としがちな抜け漏れを指摘します。

### 🚢 「案」で終わらせない

動画は生成→タイムライン編集→スマホ素材の合成→書き出しまで。記事はSEO構成→執筆→WordPress投稿。コードは計画→実行・並列ジョブ・1クリック巻き戻し・環境別デプロイ権限。**タスク管理**と `wp://` **場所リンク**で、「探さずに、その続きから」始められます。

アップロード・投稿・デプロイ・送信など**公開系だけ承認を挟み**、それ以外は自動で進みます。

### 📱 スマホ操縦席

外出先からスマホでMacのAIへ。**運転中でも使える全画面の音声モード**で、話す→作業が進む→要約が返る。撮った写真・動画もそのままプロジェクトへ入ります。

### 🗂 Obsidian・Claude Code と同じファイルを見る

**Obsidianの保管庫**を指定すれば、ナレッジ・ノート・分身プロフィールがそのままMarkdownとして保管庫に置かれ、**Claude Code も同じファイルを読めます**。WorkPilotが作るものは `保管庫/WorkPilot/` の中だけ。MCPと違い、**Obsidianを起動していなくても動きます**。

### 🤝 小さなチームの共有スペース

ナレッジ・スレッド・コードを、ただのフォルダ/NASで共有——**サーバー不要**。コード1つで参加。本番デプロイはリーダー限定、スタッフはステージングまで、といった権限分けも。

## ふつうのAIチャットとの違い

| | ふつうのAIチャット | WorkPilot |
|---|---|---|
| **費用** | API従量課金／また別のサブスク | **手持ちのサブスクがそのまま。追加費用なし** |
| **成果物** | 案・テキスト | 動画・画像・記事・コード・音声を**書き出し・公開まで** |
| **エンジン** | 1社に固定 | Claude / ChatGPT / Kimi / Gemini を**工程ごとに使い分け** |
| **記憶** | 毎回説明し直す | ナレッジ・スキル・ルール・人格を**装備**して持ち越す |
| **能動性** | 聞かれたら答える | **ループが定期実行**で回り続ける |
| **データ** | 事業者のサーバー | **自分のMac**（共有も自分のフォルダ/NAS） |

## ダウンロードとインストール

**[⬇ 最新版をダウンロード（DMG）](https://github.com/boice-kazuya/workpilot-releases/releases/latest)**

1. DMGを開き、**WorkPilot** を **Applications** へドラッグ
2. ダブルクリックで起動（**Apple公証取得済み**＝警告は出ません）
3. 設定→接続でAIエンジンを1つつなげば使い始められます

初回は使い方ツアーが出ます。**「WorkPilotの使い方」Q&A**も右上のヘルプから1クリック。更新はアプリ内のボタン1つで完了します。

## 動作環境

- macOS（**Apple Silicon** / arm64）
- 以下のいずれか1つ以上（ご自身のアカウント）：
  - **Claude** サブスク（Anthropic）または APIキー
  - **ChatGPT** サブスク（OpenAI）または APIキー
  - **Kimi** サブスク（Moonshot AI）
  - **Gemini** APIキー（無料枠でOK）
- 任意：Higgsfield（動画生成）・ElevenLabs（音声）・Suno（音楽）・Obsidian・WordPress

メモリ使用は、盛った構成ではなく**普通のMac**で軽く動くよう調整しています。

## プライバシーと安心

- **データはあなたのMacに。** 会話・ナレッジ・生成物はローカル保存。チーム共有も自分たちのフォルダ/NAS（外部サーバーに預けません）
- **勝手に公開しません。** アップロード・投稿・デプロイ・送信は必ず直前承認
- **勝手に課金されません。** API従量課金なし。月額サブスクの範囲で動き、残量は常時見えます
- **外に出る前に点検します。** エージェントの書き出し・コードの共有時に、APIキー・個人のパス・連絡先が混ざっていないか自動チェック
- **Apple公証取得済み**（Developer ID署名）

## よくある質問

<details>
<summary><b>APIキーは必要ですか？</b></summary>

不要です。各社の公式CLIログインを使うので、いまお持ちの Claude / ChatGPT / Kimi のサブスクがそのまま動きます。APIキーで使うこともできますが、必須ではありません。
</details>

<details>
<summary><b>知らないうちに課金が膨らみませんか？</b></summary>

従量課金のAPI呼び出しはありません。消費するのは月額プランの枠で、いまの5時間枠・週次枠の残りが画面下に常時出ています。長いWeb調査は自動的に安いモデルへ切り替わります。
</details>

<details>
<summary><b>勝手に投稿・デプロイされませんか？</b></summary>

されません。アップロード・投稿・デプロイ・メール送信など**公開に当たる操作**は必ず手前で止まって確認します。それ以外は自動で進むので、一日中「承認」を押し続けることにはなりません。
</details>

<details>
<summary><b>データはどこかへ送られますか？</b></summary>

会話・ナレッジ・生成物はあなたのMacに保存されます。チーム共有もご自身のフォルダ/NASです。指示内容は、あなたが選んだAI事業者にだけ渡ります。
</details>

<details>
<summary><b>Windows・Intel Mac では動きますか？</b></summary>

現在は Apple Silicon のみです。Windows版は開発中です。
</details>

<details>
<summary><b>ソースコードは公開されていますか？</b></summary>

現在は非公開です。このリポジトリはアプリの配布用です。不具合報告・ご要望は [Issues](https://github.com/boice-kazuya/workpilot-releases/issues) へぜひお寄せください。
</details>
