# WorkPilot

**チャットでAIに指示して、動画・画像・記事・コードを作る Mac 用デスクトップアプリ。**

バラバラのAI・ツール・データをひとつの操縦席にまとめ、あなた1人が"チーム"になる。

## 📥 ダウンロード

**[最新版をダウンロード（DMG）](https://github.com/boice-kazuya/workpilot-releases/releases/latest)**

1. DMG を開き、**WorkPilot** を **Applications** フォルダへドラッグ
2. ダブルクリックで起動（Apple 公証取得済み。「開発元を確認できません」の警告は出ません）

### 動作環境
- macOS（Apple Silicon / arm64）
- AIエンジンは各社の**サブスクリプション（公式CLIログイン）**または APIキーで動きます
  - Claude（Anthropic）/ ChatGPT（OpenAI）/ Kimi（Moonshot AI）/ Gemini API

## ✨ 主な機能
- 🧠 **マルチAIエンジン** — スレッドごとに Claude / ChatGPT / Kimi / Antigravity を切り替え
- 🔀 **マルチエンジン自動実行** — 「台本はClaudeで、サムネはGPTで」を工程分解して自動実行
- 👥 **AIチーム** — 役割を持ったエージェント達に仕事を任せる（工程表モード対応）
- 🎒 **装備** — ナレッジ・スキル・外部接続・人格をスレッドに装着。よく使う組み合わせはセット保存
- 🎬 **動画・画像・記事・コード** — 生成から編集・完成まで
- 📱 **スマホ操縦席** — iPhone から音声で指示・進捗確認
- 🔄 **自動更新** — アプリ内の更新ボタンで最新版に
